## 🎨 Customize Your Story

### Edit in GitHub
1. Go to your repository: `https://github.com/himagayathrivm1521-cyber/our-love-story`
2. Click on file (e.g., `index.html`)
3. Click ✏️ to edit
4. Make your changes
5. Commit

### Update Names
Replace "Nani & Gayu" with your names throughout all files

### Update Memories
Edit the memory cards in `index.html` with your own stories:
```html
<h3>Your Event Title</h3>
<p>Your memory description...</p>
```

### Change Colors
Edit `styles.css` CSS variables:
```css
--primary-color: #ff1493;      /* Change these colors */
--secondary-color: #ff69b4;
--accent-color: #ffb6d9;
```

### Add Your Music
Replace the audio URL in `index.html`:
```html
<source src="YOUR_MUSIC_URL_HERE" type="audio/mpeg">
```
